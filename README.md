# makingmemories.be

Eenvoudige website voor Making Memories: wat de app is, hoe je een uitnodiging aanvraagt, en de privacyverklaring.

- `index.html`: startpagina
- `privacy.html`: privacyverklaring (vul je naam en gemeente in bij de gemarkeerde plekken)
- `style.css`: opmaak
- `fonts/`: lettertype Lora (SIL Open Font License), vanaf de eigen site geladen, niet via Google
- `icon.svg`, `icon-180.png`: logo

Hosting: GitHub Pages met eigen domein `makingmemories.be`. De app zelf staat op `app.makingmemories.be` (repository b66-making-memories).
